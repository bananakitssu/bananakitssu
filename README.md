# Hey, I'm Banana Cool 👋

I'm an independent developer building software, mostly around web frameworks, authentication, and developer tools. I like taking ideas from a rough first version and turning them into something people can actually use.

## Main projects

- **[HostJS](https://github.com/bananakitssu/authtics-host)** — a Next.js-inspired framework for Node.js and React, with TypeScript/TSX support and SSR, SSG, and CSR rendering.
- **Authtics** — my first npm package and the project that got me started with publishing packages.
- **[Authtics Advisories](https://github.com/bananakitssu/found-malicious-packages)** — a project for tracking and reviewing security reports for npm and PyPI packages.

## Other projects and experiments

- **[UI Tools](https://github.com/bananakitssu/ui-tools)** — a React and TypeScript component library with an optional Node.js terminal backend. It's currently in beta.
- **[CatAI](https://github.com/bananakitssu/catai)** — a decoder-only language model experiment.
- **Banana** — a platform project I'm building around app deployment and hosting.
- **BTDPE** — discontinued development. I moved on to building its successor, BEngine.
- **BEngine** — a private project currently in development.

Some of my other projects are AI-assisted, and they're at different stages of development. I try to be clear about what's active, experimental, private, or discontinued.

## What I use

JavaScript, TypeScript, Node.js, React, and Python.
